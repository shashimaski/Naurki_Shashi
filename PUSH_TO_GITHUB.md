# Pushing NaukriAutomator to GitHub

This folder is a clean source-only snapshot of the NaukriAutomator project, ready to be initialised as a git repo and pushed to GitHub.

**Prepared:** 2026-07-16, refreshed 2026-07-17 by Adikarthik Gupta C B
**Snapshot source:** `F:\views\g\Naukri\` at HEAD + uncommitted working-tree changes
**Snapshot size:** ~1.38 MB across 218 files (pure source + docs)

**Ships with these post-v0.1.0 fixes:**
- 2026-07-16 real-Naukri alignment pass (selectors, smart rename, sniffed download URL, shared toast, drawer-based logout)
- 2026-07-17 already-logged-in guard in `NaukriAutomator.doLoginAttempt` — persistent Chromium session cookies no longer trigger a login-retry loop against real Naukri. Two guards short-circuit the LOGIN step when the URL matches `.*(mnjuser|homepage|profile|dashboard).*` at either the initial `page.navigate(baseUrl)` or the fallback `page.navigate(baseUrl + "/nlogin/login")` (Naukri redirects both back to `/mnjuser/homepage` when a valid session cookie is present).
- Mock-naukri enhanced to model both behaviours (GET `/` and `/nlogin/login` with session cookie both redirect to `/mnjuser/homepage`; dashboard has drawer + `[data-type='logoutLink']` markup) so integration tests exercise the guard paths.

## Initialise the git repo and push

Assuming you already created an empty repo on GitHub (e.g. `github.com/<you>/naukri-automator`):

```powershell
cd F:\views\g\Naukri-Repo

git init
git add .
git commit -m "Initial commit - NaukriAutomator v0.1.0 (2026-07-16 real-Naukri alignment)"

git branch -M main
git remote add origin https://github.com/<you>/naukri-automator.git
git push -u origin main
```

If you're using SSH instead of HTTPS:

```powershell
git remote add origin git@github.com:<you>/naukri-automator.git
```

## After a fresh clone — build from source

Prerequisites (same as `README.md`):

| Requirement | Version |
|---|---|
| Windows | 10 / 11 |
| Java | 17 (Temurin/Azul recommended) |
| Node.js | 20 LTS |
| Maven | 3.9+ |
| PowerShell | 5.1+ |

Then:

```powershell
git clone https://github.com/<you>/naukri-automator.git
cd naukri-automator

# Full build - fetches JRE, installs Playwright Chromium, builds BE + FE, packages Electron
.\build\build.ps1

# Result:
#   dist\NaukriAutomator Setup 0.1.0.exe   (NSIS installer, ~397 MB)
#   dist\NaukriAutomator 0.1.0.exe         (portable EXE, ~397 MB)
```

Individual phases:

```powershell
.\build\phases\build-backend.ps1      # mvn -f backend\pom.xml package
.\build\phases\build-mock.ps1         # mvn -f mock-naukri\pom.xml package
.\build\phases\build-frontend.ps1     # npm ci + vite build
.\build\phases\build-electron.ps1     # electron-builder --win nsis portable
```

## Run tests after a fresh clone

```powershell
.\build\test.ps1               # full: BE + Mock + FE + Electron + E2E
.\build\test.ps1 -SkipE2E      # everything except E2E

# Individual layers
$env:JAVA_HOME = 'C:\path\to\jdk-17'
mvn -f backend\pom.xml verify
mvn -f mock-naukri\pom.xml test
npm --prefix frontend run test:ci
npm --prefix electron test
```

Test totals at the time of this snapshot: BE **49/49** GREEN, Mock **13/13** GREEN (up from 8 — added 5 cases covering the already-logged-in redirect paths + drawer markup), FE **103/103** GREEN, Electron **6/6** GREEN. Integration tests (`@Tag("integration")`) require Playwright Chromium and take longer — run via `mvn verify`.

## Recommended GitHub setup

**Suggested `.github/workflows/ci.yml`** (not included in this snapshot — add per-need):

```yaml
name: CI

jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - name: Mock tests

        run: npm --prefix frontend ci; npm --prefix frontend run test:ci
```
